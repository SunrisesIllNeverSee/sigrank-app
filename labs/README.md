(mp4/gif) and the renderers that produce them. About 1.1 GB.

- Start with `promo-kit/START-HERE.txt`.
- The current kit is `promo-kit/2026-10-13-promo-kit/`. Its `README.md` has
  the latest session notes (look for "pick up here").
- Moved here from `~/Downloads/SignalAF-Social-Cards-2026-10-13/` on 2026-10-20.

purpose. Don't link to `labs/`, because it isn't deployed.
