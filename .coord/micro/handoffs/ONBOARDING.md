# Onboarding

```bash
bash .coord/bin/start.sh LEAD
```

Then read, in order:

1. `REPO.yaml`
2. `AGENTS.md`
3. `.coord/micro/STATE.md`
4. tail of `.coord/micro/SCRATCHPAD.md`
5. current handoff
6. `.coord/macro/MACRO_STATE.md` when macro coordination is active

Before stopping, save state, report material work, and sign out.
