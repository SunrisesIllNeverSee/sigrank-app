# mos2es.com Integration — Governance Context

The connected `mos2es-site` repository identifies itself as the static `mos2es.com` site and describes MO§ES as a governance framework.

This document records that current surface only. A broader mos2es.com/MO§ES™ umbrella-hub redesign is a separate ecosystem conversation and is not specified by SigRank Standard v0.1.

Recommended relationship:

```text
SigRank
measures operator-layer state
        ↓
Enterprise analysis
derives cohort / workflow structure
        ↓
MO§ES
governs decisions and transformations that consume that state
```

Rules:

- MO§ES does not redefine SigRank equations.
- SigRank does not claim to be a governance system.
- Measurement lineage should be preserved when SigRank data feeds governed decisions.
- Governance can constrain how measurements are used, especially in workforce contexts.
