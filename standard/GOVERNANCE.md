# Draft Governance

## Current state

The standard is maintained inside the SigRank ecosystem while the draft is being stabilized.

## Rules

1. Published metric semantics are versioned.
2. Breaking semantic changes require a version increment.
3. Reference-field and leaderboard policy remain separable from open metric definitions.
4. Proprietary anti-gaming logic may remain proprietary without redefining the open core.
5. Draft changes should be proposed through public issues / RFCs once the standalone repository is created.

## Change path

```text
Issue / RFC
    ↓
discussion
    ↓
draft proposal
    ↓
reference implementation
    ↓
compatibility tests
    ↓
accepted / rejected
    ↓
versioned release
```
