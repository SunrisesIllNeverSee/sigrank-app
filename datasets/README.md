# Datasets

Versioned dataset releases. Each release documents its schema, source and extraction date, inclusion and exclusion criteria, transformations, methodology version, license or access terms, and anonymization review.

Research releases use `signal-##########` identifiers only and do not contain direct operator identity fields.

## Releases

- `seeded-field/` — canonical locator and source contract for the static seeded SigRank field (TokScale corpus acquired 2026-07-13, 1,628 operators). Index, pinned sources, field classification, metric registry, population ladder, classifications, surface map, gap register, and contracts. See `seeded-field/README.md`.
