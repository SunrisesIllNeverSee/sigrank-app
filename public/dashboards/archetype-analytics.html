Methodology

Method: deterministic_build_archetypes — no clustering, no randomness

Classification: Each operator is classified into one of 10 build archetypes based on three derived dimensions of their token cascade:
  Leverage = cache_read / input (how much you reuse vs fresh input)
  Velocity = output / input (how much you generate vs take in)
  Construction = cache_write / cache_read (how much new context you build per read)

Precedence (first match wins):
  1. CONVERGENT — P80 on all 3 axes (leverage ≥ 74.6, velocity ≥ 0.34, construction ≥ 0.043)
  2. KINETIC — velocity ≥ 0.80
  3. Construction branch — construction ≥ 0.02 (BUILDER / RECURSIVE / AMPLIFIER by leverage)
  4. Reuse depth branch — else (INPUT-BOUND / PRIMING / CONTEXTUAL / DEEP READER / ARCHIVIST by leverage)
